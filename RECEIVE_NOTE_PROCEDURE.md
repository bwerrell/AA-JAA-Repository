# Receive Note Procedure

## Rule
A note, report, or atom is received only when it is fetched or otherwise becomes locally visible from the governed repository, its object class and placement are intelligible, its companion receipt or equivalent provenance is present, repository governance is not violated, AI search governance is not violated for intended use, and the object is reviewed sufficiently for intended use.

## Sequence
1. Fetch or otherwise make the object locally visible.
2. Confirm object class and placement.
3. Confirm companion receipt or equivalent provenance.
4. Confirm repository governance fit.
5. Confirm AI search governance fit for intended use.
6. Review sufficiently for intended use.
7. Confirm clean or understood local state.

## Failure rule
If provenance, governance fit, or use-readiness is deficient, the Receive Note act is incomplete.

## Maxim
Visibility alone does not constitute receipt.
