# Warranted Assembly

Created: 2026-05-09T11:03:17.6998223-07:00

## Purpose

This folder is the GitHub authority/export surface for Warranted Assembly materials.

## Core rule

GitHub may host doctrine, schemas, templates, examples, releases, deidentified reports, manifests, and receipt stubs.

GitHub must not host raw reports, private identity, home addresses, private jurisdictional profiles, raw evidence, or unreviewed grievances.

## Folder guide

### 00_README

Public orientation and navigation.

### 01_PUBLIC_DOCTRINE

Public doctrine and explanatory materials.

### 02_PUBLIC_EXPORT_PACKAGE

Materials intended for individual/public use.

### 03_SCHEMAS

Machine-readable schemas and JSON templates.

### 04_TEMPLATES

Human-readable operational templates.

### 05_SAMPLE_DATA

Fake/sample data only.

### 06_PRIVACY_AND_DEIDENTIFICATION

Privacy protections, deidentification, export gates, rejection rules, and receipt-stub doctrine.

### 07_GOVERNANCE_AND_WARRANT

Warrantability, object-kind distinctions, warrant status, and action/outcome supervision.

### 08_PUBLIC_REPORTS

Reviewed, deidentified, export-cleared reports only.

### 09_REFERENCE_SETS

WA-related reference sets and atom exports.

### 10_RELEASES

Versioned release packages.

### 90_RESTRICTED_STUBS

Central-safe stubs only, never raw private material.

### 99_ARCHIVE

Deprecated or superseded public materials.

## Boundary

Public repository structure is not public clearance.

A file belongs here only if it is appropriate for its folder purpose and has passed the relevant export/governance rule.

## Maxim

Publish structure.

Protect identity.

Export only what is governed.
