# Repository Governance

## Purpose
This file states the human-readable governance of the AA/JAA active repository.

This repository is a governed promoted witness field, not an undifferentiated file store.

## Repository role
The repository serves as the active promoted repository for selected AA/JAA materials, including notes, reports, atoms, and transcripts.

Local AA/JAA systems remain the primary surfaces for:
- origination
- classification
- immediate witness capture
- first-order governance

This repository receives materials that have been deliberately promoted for shared retention, review, and governed interrogation.

## Admissible object classes
The repository may admit the following top-level classes:
- notes
- reports
- atoms
- transcripts
- schemas

Additional classes should not be introduced casually and should be governed before admission.

## Promotion rule
Materials do not enter the repository merely because they exist.

Promotion into the repository is a governed act.
Objects admitted here should be fit for retained presence in the active repository surface.

## Receipt rule
Promoted materials should be accompanied by receipt or provenance witness sufficient to show:
- what was placed
- when it was placed
- from what source or source identifier it came
- under what governing act or authority it was promoted

The document should not arrive alone.

## Search rule
Storage permission and search permission are not identical.

Materials present in the repository are searchable only under the limits defined by `AI_SEARCH_GOVERNANCE.json`.

That machine-readable governance file shall be consulted before AI interrogation is attempted.

## Governance-file rule
Repository governance files are themselves governed objects.

At minimum, the following files should remain present and authoritative at repository root:
- `README.md`
- `REPOSITORY_GOVERNANCE.md`
- `AI_SEARCH_GOVERNANCE.json`

Modification of governance files should be restricted to authorized maintainers.

## Object discipline
Repository materials should be placed in intelligible top-level locations according to class.

At minimum:
- `notes/`
- `reports/`
- `atoms/`
- `transcripts/`
- `schemas/`

Objects should be named and organized in a stable, machine-legible manner.

## Transcript rule
Formal transcripts, including Zoom-derived meeting transcripts, may be admitted as governed functional records.

Source metadata may be inherited from source systems, but governance metadata must still be added.

Transcripts are not presumed to be freely searchable merely because they are archived here.

## General rule
This repository is meant to support continuity, review, governed sharing, and selective AI-assisted use.

It is not a dumping ground for raw, ungoverned, or casually exposed material.

## Working maxim
This repository is born governed.
