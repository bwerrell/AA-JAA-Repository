# AA/JAA Active Repository

## Purpose
This repository serves as the active promoted witness repository for selected AA/JAA materials.

It is intended to hold governed, promotable artifacts such as:
- notes
- reports
- atoms
- transcripts

The repository is designed to support:
- versioned preservation
- governed sharing
- selective AI interrogation under declared limits
- continuity of work across time and operators

## Architectural role
Local AA/JAA systems remain the primary surfaces for origination, classification, immediate witness capture, and governance.

This repository is the promoted repository surface for materials that are fit to be stored, reviewed, searched, and used here under repository governance.

## Governing files
- `REPOSITORY_GOVERNANCE.md`  human-readable repository governance
- `AI_SEARCH_GOVERNANCE.json`  machine-readable AI search and interrogation limits

These governance files are to be consulted before assuming admissibility, searchability, or reuse of repository materials.

## Top-level object classes
- `notes/`  promoted notes suitable for shared use
- `reports/`  promoted reports, including official reporting artifacts
- `atoms/`  promoted atomic witness objects
- `transcripts/`  governed meeting transcripts and related records
- `schemas/`  schemas, templates, and examples for repository object structure

## General rule
Materials do not enter this repository merely because they exist.
They are promoted here deliberately and under governance.

Search permission is not identical with storage permission.

## Working maxim
Originate locally.  
Promote deliberately.  
Search under rule.
