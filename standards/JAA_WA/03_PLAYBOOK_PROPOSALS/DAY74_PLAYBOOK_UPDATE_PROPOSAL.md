## Proposed live playbook addition

### Note-memory loop

Use the following ordinary commands for governed note continuity:

WRITE Notes = append a note to the current daily append-only note file.

ATOMIZE Notes = refresh the current day's candidate atom surface.

CALL Notes = search candidate atom surfaces for relevant prior notes.

READ Notes = use selected notes or atoms as the authority field for continuation.

## Governance boundaries

WRITE saves; it does not classify, publish, promote, or adjudicate.

ATOMIZE creates candidate atoms only.

CALL retrieves; it does not prove, decide, promote, or canonicalize.

READ binds selected notes or atoms as the authority field and does not silently expand it.

## Operational rule

The operator should not need to manually browse note files during ordinary use.

The system should prefer CALL Notes against atomized memory where available.
