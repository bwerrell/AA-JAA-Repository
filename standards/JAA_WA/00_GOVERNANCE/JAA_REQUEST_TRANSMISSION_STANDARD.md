# DAY74 JAA Request-Transmission Standard

Timestamp: 2026-05-10 09:07:35

## Purpose

Define the distribution posture for JAA materials.

## Rule

JAA operating documents may be stored in GitHub for standard maintenance and administrative control.

Storage in GitHub does not imply public distribution.

JAA user-facing materials are available for governed transmission to a user when requested or authorized.

## Operating posture

JAA is request-transmitted, not ambiently shared.

## Distinctions

### Standard storage

The document is preserved and maintained as an authority surface.

### Administrator access

Authorized maintainers may update, ratchet, supersede, or promote the standard.

### User transmission

A selected package or document is transmitted to a user by request, authorization, or governed release act.

### Public publication

General availability to the public.

Public publication requires a separate governed act.

## GitHub boundary

GitHub seating proves standard placement.

GitHub seating does not by itself authorize:

- user transmission
- public publication
- legal sufficiency
- publication fitness
- canonical promotion

## Practical consequence

JAA may be maintained in GitHub without being broadly shared.

A user may receive JAA materials only through a specific request, authorization, or governed transmission act.

## Maxim

Stored as standard does not mean shared by default.

JAA is request-transmitted, not ambiently shared.
