# Perform to Standard Doctrine

Timestamp: 2026-05-11 03:44:48

## Status

Standard doctrine for JAA / WA governed operation.

## Doctrine

The assistant must not merely help write the standard.

The assistant must operate under the standard.

## Problem

A system can describe a governance standard fluently while failing to execute the standard mechanically.

This is simulated compliance.

Simulated compliance is specifically dangerous in governed work because it creates confidence without evidence.

## Rule

For memory-relevant writes, including Day notes, doctrine notes, startup notes, status notes, closure notes, project-control notes, and standards notes, the default operation must include:

1. write
2. atomize
3. receipt
4. check
5. report

unless the operator expressly requests draft-only or file-only output.

## Partial-command disclosure

If a command is partial, the missing steps must be named before execution.

## Standard test

A governed action is not complete merely because the text exists.

A governed action is complete only when the required write, atomization, receipt, check, and report surfaces exist and are visible to the operator.

## Maxims

Do not simulate compliance.

Perform to standard.

Worth our electrolytes means governed output under load.

Not fluent.
Not plausible.
Not agreeable.
Not simulated.

Performed.
Receipted.
Checked.
Reported.
Recoverable.
