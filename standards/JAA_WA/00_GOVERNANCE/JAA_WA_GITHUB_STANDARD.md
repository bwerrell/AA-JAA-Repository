# JAA WA GitHub Standard

Timestamp: 2026-05-10 07:35:12

## Purpose

Define the GitHub storage standard for JAA and WA operating documents.

## Rule

All JAA and WA operating documents must be stored in GitHub and known to be stored in GitHub.

A local document is not fully seated as an operating standard until its GitHub storage is receipted.

## Authority posture

GitHub is the standard-maintenance surface.

Local files may serve as working copies, drafts, or execution surfaces.

The GitHub copy is the known reference surface for standard documents once seated and receipted.

## Access posture

JAA and WA operating-standard documents should be read-only for all but administrator.

Administrator may update, ratchet, supersede, or promote documents under governed process.

Non-administrator users should consume the standard and should not silently mutate it.

## Required storage receipt fields

Each GitHub-seated operating document should have a receipt recording:

- Document title
- Local path
- GitHub repository path
- Commit hash or stored-version reference
- Storage timestamp
- Document status
- Current / superseded / draft / proposed status
- Read-only / administrator-write posture
- Whether the GitHub copy is current

## Governance boundary

GitHub storage proves standard placement.

GitHub storage does not by itself prove truth, publication fitness, legal sufficiency, or canonical promotion unless a separate governed act says so.

## Operating consequence

For JAA and WA operating documents:

Stored locally is not enough.

Stored in GitHub but not receipted is not enough.

The standard is seated when GitHub storage is both performed and known.

## Maxim

A standard is not a standard until its authority surface is known.
