## Operating doctrine

WRITE Notes = append a note to the current daily append-only note file.

ATOMIZE Notes = refresh the current day's candidate atom surface.

CALL Notes = search candidate atom surfaces for relevant prior notes.

READ Notes = use selected notes or atoms as the authority field for continuation.

## Governance boundary

GitHub seating proves standard placement.

It does not by itself prove truth, publication fitness, legal sufficiency, or canonical promotion unless a separate governed act says so.

## Maxim

A standard is shared when a user can find the current surface without private explanation.
