# JAA Public User Quickstart

Timestamp: 2026-05-10 07:56:59

## What JAA is

JAA is a local note-memory system.

It helps you write notes, preserve them, find them later, and continue work from what you actually wrote.

## What JAA is for

Use JAA when you want your thoughts, observations, decisions, project notes, or daily work to become recoverable instead of scattered.

## The four commands

### WRITE Notes

Save this note into today's note file.

Use when something matters and should not be lost.

### ATOMIZE Notes

Make today's notes searchable.

Use at the end of a day or after a substantial work session.

### CALL Notes

Search prior notes for relevant memory.

Use when you want to recover something you previously wrote.

### READ Notes

Use selected notes or atoms as the authority field for continuation.

Use when you want the next answer or work product to continue from the selected notes.

## First thing to do

Start by writing one note.

Example:

WRITE Notes: Today I began using JAA so that my work can be preserved, recovered, and continued from what I actually wrote.

## What not to expect

JAA does not decide what is true.

JAA does not publish your notes by default.

JAA does not replace your judgment.

JAA does not silently turn working notes into final official records.
