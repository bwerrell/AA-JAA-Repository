# JAA Minimal Command Guide

Timestamp: 2026-05-10 07:22:07

## Purpose

This guide gives the ordinary user the smallest useful command set for JAA.

## Command 1  WRITE Notes

Use when you want to save a thought, observation, task, event, decision, or idea.

Plain meaning:

Save this note in today's note file.

Example:

WRITE Notes: I spoke with Rob today about the public JAA package. The key issue is making the system useful without requiring the user to understand the machinery.

## Command 2  ATOMIZE Notes

Use when you want today's notes converted into a searchable candidate memory surface.

Plain meaning:

Make today's notes searchable.

Best time to use:

At the end of the day, or after a major work session.

## Command 3  CALL Notes

Use when you want to recover something previously written.

Plain meaning:

Search my notes for this topic.

Example:

CALL Notes: Rob public JAA package

## Command 4  READ Notes

Use when you want selected notes or atoms to become the working context for continuation.

Plain meaning:

Use these selected notes as the authority field for the next answer or next work product.

## Boundaries

WRITE saves.

ATOMIZE prepares.

CALL retrieves.

READ binds selected material for continuation.

None of these commands publish, adjudicate, or silently promote notes into final records.

## Maxim

Four commands are enough to begin.
